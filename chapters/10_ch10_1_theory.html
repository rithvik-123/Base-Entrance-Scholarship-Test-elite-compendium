1. Arithmetic Progressions (AP): Structure, Traps & Power Tools

First-Principles Foundation

A sequence $T_1, T_2, T_3, \dots, T_n$ is an Arithmetic Progression (AP) if the difference between every pair of consecutive terms is a constant $d$ (called the common difference):

$$T_{k+1} - T_k = d \quad \text{for all } k \ge 1.$$

Setting $T_1 = a$, telescoping the constant step $n - 1$ times yields the general ($n$-th) term:

$$T_n = a + (n - 1)d = dn + (a - d).$$

Algebraic Signature of an AP: $T_n$ is always a linear polynomial in $n$ (of the form $pn + q$), where the coefficient of $n$ is identically the common difference ($d = p$). Conversely, any sequence whose $n$-th term is linear in $n$ is guaranteed to be an AP.

Derivation of the Sum $S_n$ (Gauss Pairing Method): Let $l = T_n = a + (n - 1)d$ denote the last term. Write $S_n$ forward and backward and add column-by-column:

$$ \begin{aligned} S_n &= a + (a + d) + (a + 2d) + \dots + (l - d) + l \\ S_n &= l + (l - d) + (l - 2d) + \dots + (a + d) + a \\ \hline 2S_n &= \underbrace{(a + l) + (a + l) + \dots + (a + l)}_{n \text{ identical pairs}} = n(a + l). \end{aligned} $$

Dividing by $2$ and substituting $l = a + (n - 1)d$ produces both standard forms:

$$S_n = \frac{n}{2}(a + l) = \frac{n}{2}\bigl[2a + (n - 1)d\bigr].$$

Figure 10.1: Visual staircase pairing. Every pair of equidistant terms $(T_k + T_{n+1-k})$ locks to the exact same height $(a + l)$, collapsing the staircase into half a rectangle.

Spotting an AP Instantly from $S_n$

Expand the standard sum formula:

$$S_n = \frac{n}{2}\bigl[2a + (n - 1)d\bigr] = \left(\frac{d}{2}\right)n^2 + \left(a - \frac{d}{2}\right)n = An^2 + Bn.$$

Matching coefficients gives an instantaneous extraction rule whenever $S_n = An^2 + Bn$ (with zero constant term):

  • Common difference: $d = 2A$ (twice the coefficient of $n^2$).
  • First term: $T_1 = S_1 = A + B$.
  • General term: $T_n = S_n - S_{n-1} = \bigl(An^2 + Bn\bigr) - \bigl(A(n-1)^2 + B(n-1)\bigr) = 2An + (B - A)$.
Critical Exam Trap: The Non-Zero Constant $C$ in $S_n = An^2 + Bn + C$

BEST examiners love giving $S_n = An^2 + Bn + C$ with $C \neq 0$ and asking whether the sequence is an AP or asking for $T_1$ and $d$. Do NOT blindly apply $T_n = S_n - S_{n-1}$ for $n = 1$!

  • The identity $T_n = S_n - S_{n-1}$ is valid only for $n \ge 2$ (since $S_0$ is not defined as $C$; rather, $T_1$ is strictly $S_1$).
  • Here $T_1 = S_1 = A + B + C$, whereas for $n \ge 2$, the constant $C$ cancels out: $$T_n = S_n - S_{n-1} = 2An + (B - A) \quad (n \ge 2).$$
  • Check the first two gaps: $$T_2 - T_1 = (3A + B) - (A + B + C) = 2A - C, \qquad T_3 - T_2 = (5A + B) - (3A + B) = 2A.$$
  • Verdict: If $C \neq 0$, the sequence is NOT an AP from the 1st term—it becomes an AP with common difference $d = 2A$ strictly from the 2nd term onwards ($T_2, T_3, T_4, \dots$).
Resonance / Olympiad Bridge: AP Power Techniques

1. Symmetric Term Selection (Canceling $d$ on Addition): When the sum of a small number of terms in an AP is given, choose terms symmetrically around the mean so $d$ vanishes immediately:

  • 3 terms: $a - d,\; a,\; a + d$ (common difference $= d$; sum $= 3a$).
  • 4 terms: $a - 3d,\; a - d,\; a + d,\; a + 3d$ (common difference $= 2d$; sum $= 4a$).
  • 5 terms: $a - 2d,\; a - d,\; a,\; a + d,\; a + 2d$ (common difference $= d$; sum $= 5a$).

2. Ratio of Sums $\leftrightarrow$ Ratio of $n$-th Terms (The $n \to 2n - 1$ Theorem): Suppose two APs have sums $S_k$ and $S'_k$ with known ratio $\dfrac{S_k}{S'_k} = f(k)$. Divide numerator and denominator by $\dfrac{k}{2}$ and then by $2$:

$$\frac{S_k}{S'_k} = \frac{\frac{k}{2}[2a_1 + (k-1)d_1]}{\frac{k}{2}[2a_2 + (k-1)d_2]} = \frac{a_1 + \left(\frac{k-1}{2}\right)d_1}{a_2 + \left(\frac{k-1}{2}\right)d_2}.$$

Compare this with $\dfrac{T_n}{T'_n} = \dfrac{a_1 + (n - 1)d_1}{a_2 + (n - 1)d_2}$. Equating coefficients of $d$:

$$\frac{k - 1}{2} = n - 1 \iff k = 2n - 1.$$
  • From $\frac{S_n}{S'_n}$ to $\frac{T_n}{T'_n}$: Replace $n$ by $2n - 1$.
  • From $\frac{T_n}{T'_n}$ to $\frac{S_n}{S'_n}$: Replace $n$ by $\dfrac{n + 1}{2}$.

3. Inserting $k$ Arithmetic Means ($A_1, A_2, \dots, A_k$) between $a$ and $b$: The sequence $a, A_1, A_2, \dots, A_k, b$ is an AP of $(k + 2)$ terms, where $T_{k+2} = b$:

$$b = a + (k + 1)d \implies d = \frac{b - a}{k + 1}, \qquad A_m = a + m\left(\frac{b - a}{k + 1}\right) \quad (1 \le m \le k).$$

Sum of all $k$ Arithmetic Means: By equidistant pairing ($A_1 + A_k = a + b$),

$$\sum_{m=1}^{k} A_m = \frac{k}{2}(A_1 + A_k) = k\left(\frac{a + b}{2}\right) = k \times (\text{single AM between } a \text{ and } b).$$

2. Geometric Progressions (GP): Finite Sums, Infinite Convergence & Geometric Decays

First-Principles Foundation

A non-zero sequence $T_1, T_2, T_3, \dots$ is a Geometric Progression (GP) if the ratio of every consecutive pair is a fixed non-zero constant $r$ (the common ratio):

$$\frac{T_{k+1}}{T_k} = r \quad \implies \quad T_n = a r^{n-1} \quad (a \neq 0,\; r \neq 0).$$

Derivation of the Finite Sum $S_n$ (Shift-and-Subtract): Write $S_n$, multiply through by $r$, and subtract:

$$ \begin{aligned} S_n &= a + ar + ar^2 + \dots + ar^{n-1} \\ rS_n &= \phantom{a +\;} ar + ar^2 + \dots + ar^{n-1} + ar^n \\ \hline (1 - r)S_n &= a - ar^n = a(1 - r^n). \end{aligned} $$

Therefore:

$$S_n = \begin{cases} \dfrac{a(1 - r^n)}{1 - r} = \dfrac{a(r^n - 1)}{r - 1}, & r \neq 1, \\[10pt] na, & r = 1. \end{cases}$$

Infinite GP Sum ($S_\infty$): As $n \to \infty$, the term $r^n$ approaches $0$ if and only if $|r| \lt 1$ (i.e., $-1 \lt r \lt 1$). Taking the limit of $S_n = \dfrac{a(1 - r^n)}{1 - r}$:

$$S_\infty = \frac{a}{1 - r} \qquad \textbf{STRICTLY VALID ONLY FOR } |r| \lt 1.$$

If $|r| \ge 1$ and $a \neq 0$, the partial sums do not settle to a finite limit—the series diverges. Never plug $r = 2$ or $r = -1$ into $\frac{a}{1-r}$!

High-Yield Applications: Recurring Decimals & Nested Geometric Figures

1. Recurring Decimals as Infinite GPs: Any repeating decimal splits into a non-repeating prefix plus a strictly convergent infinite GP. For example:

$$0.2\overline{45} = 0.2 + 0.045 + 0.00045 + 0.0000045 + \dots = \frac{2}{10} + \frac{45/1000}{1 - 1/100} = \frac{1}{5} + \frac{45}{990} = \frac{1}{5} + \frac{1}{22} = \frac{27}{110}.$$

2. Nested Geometric Figures (Similarity Scaling Law): Whenever a figure $F_{k+1}$ is inscribed similarly inside $F_k$ with linear scale factor $\lambda$ ($0 \lt \lambda \lt 1$):

  • Perimeters (1D) form a GP with ratio $r_P = \lambda \implies P_\infty = \dfrac{P_1}{1 - \lambda}$.
  • Areas (2D) form a GP with ratio $r_A = \lambda^2 \implies A_\infty = \dfrac{A_1}{1 - \lambda^2}$.
  • Classic Midpoint Benchmark Values: Joining midpoints of a square gives $\lambda = \dfrac{1}{\sqrt{2}}$, $\lambda^2 = \dfrac{1}{2}$; joining midpoints of an equilateral triangle gives $\lambda = \dfrac{1}{2}$, $\lambda^2 = \dfrac{1}{4}$.

Resonance / Olympiad Bridge: GP Structural Properties & Geometric Means

1. Symmetric GP Term Selection (Canceling $r$ on Multiplication): When the product of terms is given:

  • 3 terms: $\dfrac{a}{r},\; a,\; ar$ (common ratio $= r$; product $= a^3$).
  • 4 terms: $\dfrac{a}{r^3},\; \dfrac{a}{r},\; ar,\; ar^3$ (common ratio $= r^2$; product $= a^4$).
  • 5 terms: $\dfrac{a}{r^2},\; \dfrac{a}{r},\; a,\; ar,\; ar^2$ (common ratio $= r$; product $= a^5$).

2. Equidistant Product Property: In any finite GP $T_1, T_2, \dots, T_n$:

$$T_k \cdot T_{n+1-k} = \bigl(ar^{k-1}\bigr)\bigl(ar^{n-k}\bigr) = a^2 r^{n-1} = T_1 \cdot T_n = \text{constant}.$$

Consequently, the product $P_n$ of all $n$ terms satisfies $P_n^2 = (T_1 T_n)^n \implies P_n = (T_1 T_n)^{n/2}$. If $n$ is odd with middle term $T_m$ ($m = \frac{n+1}{2}$), then $T_1 T_n = T_m^2$, so $P_n = (T_m)^n$!

3. Inserting $k$ Geometric Means ($G_1, G_2, \dots, G_k$) between positive $a$ and $b$: The GP $a, G_1, \dots, G_k, b$ has $(k + 2)$ terms, giving $b = a r^{k+1}$:

$$r = \left(\frac{b}{a}\right)^{\frac{1}{k+1}}, \qquad G_m = a \left(\frac{b}{a}\right)^{\frac{m}{k+1}} \quad (1 \le m \le k).$$

Product of all $k$ Geometric Means: Pairing $G_1 G_k = G_2 G_{k-1} = \dots = ab$:

$$\prod_{m=1}^{k} G_m = (ab)^{k/2} = \bigl(\sqrt{ab}\bigr)^k = (\text{single GM between } a \text{ and } b)^k.$$

3. Arithmetico-Geometric Progression (AGP) & The Shift-and-Subtract Engine

Resonance / Olympiad Bridge: AGP Derivation from First Principles

An Arithmetico-Geometric Progression (AGP) is formed by multiplying corresponding terms of an AP $\{a + (k-1)d\}$ and a GP $\{r^{k-1}\}$:

$$S_n = a + (a + d)r + (a + 2d)r^2 + \dots + \bigl[a + (n - 1)d\bigr]r^{n-1}.$$

Rule #1 of Olympiad Algebra: Do not memorize the finite AGP formula blindly—master the 3-line shift-and-subtract engine! Multiply $S_n$ by the GP ratio $r$, shift one column right so identical powers of $r$ align, and subtract:

$$ \begin{aligned} S_n &= a + (a + d)r + (a + 2d)r^2 + \dots + \bigl[a + (n - 1)d\bigr]r^{n-1} \\ rS_n &= \phantom{a +\;} ar \phantom{\;+\; d} + (a + d)r^2 + \dots + \bigl[a + (n - 2)d\bigr]r^{n-1} + \bigl[a + (n - 1)d\bigr]r^n \\ \hline (1 - r)S_n &= a + \underbrace{dr + dr^2 + \dots + dr^{n-1}}_{\text{Pure GP of }(n-1)\text{ terms}} - \bigl[a + (n - 1)d\bigr]r^n. \end{aligned} $$

Evaluating the pure GP $\sum_{k=1}^{n-1} dr^k = \dfrac{dr(1 - r^{n-1})}{1 - r}$ (for $r \neq 1$) and dividing by $(1 - r)$:

$$S_n = \frac{a}{1 - r} + \frac{dr(1 - r^{n-1})}{(1 - r)^2} - \frac{\bigl[a + (n - 1)d\bigr]r^n}{1 - r} \qquad (r \neq 1).$$

Infinite AGP Sum ($|r| \lt 1$): When $|r| \lt 1$, exponential decay beats linear growth, so both $\lim_{n\to\infty} r^n = 0$ and $\lim_{n\to\infty} n r^n = 0$. The finite formula collapses cleanly to:

$$S_\infty = \frac{a}{1 - r} + \frac{dr}{(1 - r)^2} \qquad (|r| \lt 1).$$

Olympiad Power Upgrade: What if the coefficients are quadratic in $k$ (e.g., $\sum_{k=1}^\infty k^2 r^k$)? Simply apply shift-and-subtract twice: the first subtraction converts quadratic coefficients into linear ones (an AGP), and the second converts the AGP into a pure GP!

4. Special Series & Telescopic Cancellation ($V_n$ Method)

Standard Power Sums & Proof Strategy

The three foundational sigma identities are built from polynomial telescoping:

  1. Sum of first $n$ natural numbers: $\displaystyle \sum_{k=1}^{n} k = 1 + 2 + \dots + n = \frac{n(n + 1)}{2}$.
  2. Sum of squares of first $n$ natural numbers: $\displaystyle \sum_{k=1}^{n} k^2 = 1^2 + 2^2 + \dots + n^2 = \frac{n(n + 1)(2n + 1)}{6}$.
  3. Sum of cubes of first $n$ natural numbers: $\displaystyle \sum_{k=1}^{n} k^3 = 1^3 + 2^3 + \dots + n^3 = \left[\frac{n(n + 1)}{2}\right]^2 = \left(\sum_{k=1}^{n} k\right)^2$.

First-Principles Proof of $\sum k^2$: Start from the algebraic identity $(k + 1)^3 - k^3 = 3k^2 + 3k + 1$. Sum from $k = 1$ to $n$:

$$(n + 1)^3 - 1^3 = 3\sum_{k=1}^{n} k^2 + 3\sum_{k=1}^{n} k + \sum_{k=1}^{n} 1.$$

Substitute $\sum k = \dfrac{n(n+1)}{2}$ and $\sum 1 = n$, then isolate $3\sum k^2$:

$$3\sum_{k=1}^{n} k^2 = (n^3 + 3n^2 + 3n) - \frac{3n(n+1)}{2} - n = \frac{2n^3 + 3n^2 + n}{2} = \frac{n(n+1)(2n+1)}{2} \implies \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}.$$

Alternating Square Differences Pattern: To evaluate $m^2 - (m-1)^2 + (m-2)^2 - (m-3)^2 + \dots$, pair consecutive terms using $x^2 - y^2 = (x - y)(x + y)$ where $(x - y) = 1$:

$$50^2 - 49^2 + 48^2 - 47^2 + \dots + 2^2 - 1^2 = (50 + 49) + (48 + 47) + \dots + (2 + 1) = \sum_{k=1}^{50} k = \frac{50 \times 51}{2} = 1275.$$

Parity Check: If the highest term is odd (e.g., $51^2 - 50^2 + \dots - 2^2 + 1^2$), the lone $+1^2$ remains at the end, still yielding $51 + 50 + \dots + 2 + 1 = \frac{51 \times 52}{2} = 1326$!

Resonance / Olympiad Bridge: The Telescopic ($V_n$) Difference Method

Whenever a general term $T_k$ can be rewritten as the difference of two consecutive evaluations of a single helper function—either $T_k = V_k - V_{k-1}$ or $T_k = U_k - U_{k+1}$—all interior terms annihilate each other, leaving only the two boundary terms:

$$\sum_{k=1}^{n} (V_k - V_{k-1}) = V_n - V_0, \qquad \sum_{k=1}^{n} (U_k - U_{k+1}) = U_1 - U_{n+1}.$$

The 4 Master Telescopic Splits Tested in BEST / IOQM:

  • 2-Factor Partial Fractions: $\displaystyle \frac{1}{k(k + 1)} = \frac{1}{k} - \frac{1}{k + 1} \implies \sum_{k=1}^{n} \frac{1}{k(k+1)} = 1 - \frac{1}{n + 1} = \frac{n}{n + 1}$.
  • General Step-$d$ Partial Fractions: $\displaystyle \frac{1}{a_k \cdot a_{k+1}} = \frac{1}{d}\left(\frac{1}{a_k} - \frac{1}{a_{k+1}}\right)$ when $\{a_k\}$ is an AP with difference $d = a_{k+1} - a_k$.
  • 3-Factor Partial Fractions: Peel off the first and last factors whose difference is $(k + 2) - k = 2$: $$\frac{1}{k(k + 1)(k + 2)} = \frac{1}{2}\left[\frac{1}{k(k + 1)} - \frac{1}{(k + 1)(k + 2)}\right].$$ Summing from $k = 1$ to $n$ gives $\dfrac{1}{2}\left[\dfrac{1}{1 \cdot 2} - \dfrac{1}{(n + 1)(n + 2)}\right] = \dfrac{n(n + 3)}{4(n + 1)(n + 2)}$.
  • Radical Rationalization Telescoping: Multiply by the conjugate so the denominator becomes a constant step $d$: $$\frac{1}{\sqrt{k} + \sqrt{k + 1}} = \frac{\sqrt{k + 1} - \sqrt{k}}{(k + 1) - k} = \sqrt{k + 1} - \sqrt{k} \implies \sum_{k=1}^{n} \frac{1}{\sqrt{k} + \sqrt{k + 1}} = \sqrt{n + 1} - 1.$$
  • Numerator Product Telescoping: Insert the next and previous AP factors: $$k(k + 1) = \frac{1}{3}\Bigl[k(k + 1)(k + 2) - (k - 1)k(k + 1)\Bigr] \implies \sum_{k=1}^{n} k(k + 1) = \frac{n(n + 1)(n + 2)}{3}.$$

5. The AM–GM–HM Inequality: Geometry, Optimization & Traps

Resonance / Olympiad Bridge: Mean Inequality Hierarchy

For any $n$ strictly positive real numbers $x_1, x_2, \dots, x_n \gt 0$, define the three classical means:

$$\text{AM} = \frac{x_1 + x_2 + \dots + x_n}{n}, \qquad \text{GM} = \bigl(x_1 x_2 \cdots x_n\bigr)^{1/n}, \qquad \text{HM} = \frac{n}{\frac{1}{x_1} + \frac{1}{x_2} + \dots + \frac{1}{x_n}}.$$

Fundamental Theorem (AM–GM–HM Inequality):

$$\text{AM} \ge \text{GM} \ge \text{HM},$$

with equality holding if and only if $x_1 = x_2 = \dots = x_n$.

Algebraic Proof for $n = 2$ ($a, b \gt 0$):

$$\text{AM} - \text{GM} = \frac{a + b}{2} - \sqrt{ab} = \frac{(\sqrt{a} - \sqrt{b})^2}{2} \ge 0, \qquad \text{GM} - \text{HM} = \sqrt{ab} - \frac{2ab}{a + b} = \frac{\sqrt{ab}(\sqrt{a} - \sqrt{b})^2}{a + b} \ge 0.$$

Notice also the exact geometric link for two positive numbers: $\text{AM} \cdot \text{HM} = \left(\dfrac{a+b}{2}\right)\left(\dfrac{2ab}{a+b}\right) = ab = (\text{GM})^2$, meaning $\text{AM}, \text{GM}, \text{HM}$ themselves form a GP!

Core Optimization Corollary:

  • If the product $x_1 x_2 \cdots x_n = P$ (constant), then the sum $x_1 + \dots + x_n$ attains its minimum $n P^{1/n}$ when all $x_i$ are equal.
  • If the sum $x_1 + \dots + x_n = S$ (constant), then the product $x_1 x_2 \cdots x_n$ attains its maximum $(S/n)^n$ when all $x_i$ are equal.
  • Reciprocal Benchmark: For every $x \gt 0$, $x + \dfrac{1}{x} \ge 2$ (equality at $x = 1$).

Figure 10.4: Complete geometric proof of $\text{AM} \ge \text{GM} \ge \text{HM}$ on a semicircle of diameter $a + b$. In right $\triangle OHP$, hypotenuse $OP \ge$ leg $PH$; in right $\triangle PKH$, hypotenuse $PH \ge$ leg $PK$. Equality collapses all three segments to the vertical radius iff $H = O$ ($a = b$).

Two Lethal AM–GM Traps That Destroy Unprepared Students
  1. The Positivity Trap: AM–GM requires every term to be strictly positive. If $x \lt 0$, let $y = -x \gt 0$; then $y + \frac{1}{y} \ge 2 \implies x + \frac{1}{x} \le -2$. Never claim $x + \frac{1}{x} \ge 2$ for arbitrary real $x \neq 0$!
  2. The Unattainable Equality Trap: Even when every term is positive, the lower bound from AM–GM is the true minimum only if the equality condition ($x_1 = x_2 = \dots = x_n$) has a real solution inside the allowed domain! For example, in $t + \frac{4}{t}$ where $t = \sqrt{x^2 + 9} \ge 3$, AM–GM yields $\ge 4$ with equality at $t = 2$, which is impossible since $t \ge 3$. (See Worked Example 7(b) for the exact resolution.)

6. 3-Variable Algebraic Identities & The Two-Branch Cubic Theorem

Resonance / Olympiad Bridge: The Three Master Identities

Identity 1 (Square of a Trinomial):

$$(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca).$$

Identity 2 (The Sum-of-Squares Non-Negativity Identity): Multiply by $2$, regroup into three perfect squares, and divide by $2$:

$$a^2 + b^2 + c^2 - ab - bc - ca = \frac{1}{2}\Bigl[(a - b)^2 + (b - c)^2 + (c - a)^2\Bigr].$$

Consequences for all real numbers $a, b, c \in \mathbb{R}$:

  • $a^2 + b^2 + c^2 - ab - bc - ca \ge 0$ unconditionally, i.e., $a^2 + b^2 + c^2 \ge ab + bc + ca$.
  • Zero-Sum Trap: Since a sum of real squares vanishes if and only if each individual square is zero: $$a^2 + b^2 + c^2 = ab + bc + ca \iff (a - b)^2 + (b - c)^2 + (c - a)^2 = 0 \iff a = b = c.$$
  • Lightning Numerical Shortcut: Whenever $a, b, c$ are large numbers that are close together (e.g., $998, 999, 1001$), never square them—compute $\frac{1}{2}[(a-b)^2 + (b-c)^2 + (c-a)^2]$ in 5 seconds.

Identity 3 (The Master 3-Variable Cubic Factorization):

$$ \begin{aligned} a^3 + b^3 + c^3 - 3abc &= (a + b + c)(a^2 + b^2 + c^2 - ab - bc - ca) \\ &= \frac{1}{2}(a + b + c)\Bigl[(a - b)^2 + (b - c)^2 + (c - a)^2\Bigr] \\ &= (a + b + c)\Bigl[(a + b + c)^2 - 3(ab + bc + ca)\Bigr]. \end{aligned} $$

Proof of the 3-Variable AM–GM as an Immediate Corollary: For any positive reals $x, y, z \gt 0$, substitute $a = x^{1/3},\; b = y^{1/3},\; c = z^{1/3}$. Since $a + b + c \gt 0$ and $(a-b)^2 + (b-c)^2 + (c-a)^2 \ge 0$, we immediately obtain $x + y + z - 3(xyz)^{1/3} \ge 0 \iff \dfrac{x + y + z}{3} \ge (xyz)^{1/3}$!

Critical Exam Trap: Both Branches of $a^3 + b^3 + c^3 = 3abc$

In Class 9/10 school exams, students memorize only one direction: "If $a + b + c = 0$, then $a^3 + b^3 + c^3 = 3abc$." In BEST / IOQM, problems reverse the arrow and give $a^3 + b^3 + c^3 = 3abc$. Because the factorization is a product of two factors:

$$a^3 + b^3 + c^3 = 3abc \iff \underbrace{a + b + c = 0}_{\textbf{Branch 1}} \quad \mathbf{OR} \quad \underbrace{a = b = c}_{\textbf{Branch 2}}.$$
  • If the problem states $a, b, c \gt 0$ (or $a + b + c \neq 0$), Branch 1 is eliminated and you are forced into $a = b = c$.
  • If the problem states $a, b, c$ are distinct (not all equal), Branch 2 is eliminated and you are forced into $a + b + c = 0$.

Level 1 AP • $S_n$ Constant Trap Worked Example 1: Dissecting $S_n = 3n^2 + 5n + 2$
For a sequence $\{a_n\}$, the sum of the first $n$ terms is given by $S_n = 3n^2 + 5n + 2$ for all positive integers $n$.
(a) Find $a_1$, $a_2$, $a_3$, and a closed-form expression for $a_n$ valid for $n \ge 2$.
(b) State whether $\{a_n\}$ is an Arithmetic Progression from $n = 1$ or from $n = 2$, and calculate $a_{20}$.

Step 1 — Compute $a_1$ directly from $S_1$:

$$a_1 = S_1 = 3(1)^2 + 5(1) + 2 = 3 + 5 + 2 = 10.$$

Step 2 — Derive $a_n$ for $n \ge 2$ using $a_n = S_n - S_{n-1}$:

First expand $S_{n-1}$ carefully:

$$S_{n-1} = 3(n - 1)^2 + 5(n - 1) + 2 = 3(n^2 - 2n + 1) + 5n - 5 + 2 = 3n^2 - 6n + 3 + 5n - 3 = 3n^2 - n.$$

Now subtract:

$$a_n = S_n - S_{n-1} = (3n^2 + 5n + 2) - (3n^2 - n) = 6n + 2 \qquad (n \ge 2).$$

Step 3 — Compute $a_2, a_3$ and verify against direct partial sums:

  • $a_2 = 6(2) + 2 = 14$. (Check: $S_2 = 3(4) + 5(2) + 2 = 24 \implies S_2 - S_1 = 24 - 10 = 14$.)
  • $a_3 = 6(3) + 2 = 20$. (Check: $S_3 = 3(9) + 5(3) + 2 = 44 \implies S_3 - S_2 = 44 - 24 = 20$.)

Step 4 — Check AP status and find $a_{20}$:

Notice that $a_2 - a_1 = 14 - 10 = 4$, whereas for every $n \ge 3$, $a_n - a_{n-1} = (6n + 2) - [6(n-1) + 2] = 6$. Because the constant term $C = 2 \neq 0$, the first gap is reduced by $C$ ($2A - C = 6 - 2 = 4$).

Therefore, $\{a_n\}$ is NOT an AP from $n = 1$, but IS an AP from $n = 2$ onwards with common difference $d = 6$. Finally, since $20 \ge 2$:

$$a_{20} = 6(20) + 2 = \mathbf{122}.$$
Level 1 Infinite GP • Nested Geometry Worked Example 2: Infinite Sequence of Midpoint Equilateral Triangles
An equilateral triangle $T_1$ has side length $16\text{ cm}$. A second equilateral triangle $T_2$ is formed by joining the midpoints of the sides of $T_1$; $T_3$ is formed by joining the midpoints of $T_2$, and this process continues indefinitely. Find:
(a) the sum of the perimeters of all triangles $T_1, T_2, T_3, \dots$;
(b) the sum of the areas of all triangles $T_1, T_2, T_3, \dots$.

Step 1 — Establish the similarity scaling ratio:

By the Midpoint Theorem, each segment joining the midpoints of two sides of a triangle is parallel to and half the length of the third side. Thus every triangle $T_k$ is equilateral with side length $s_k = \dfrac{1}{2} s_{k-1}$:

$$s_1 = 16,\quad s_2 = 8,\quad s_3 = 4,\quad \dots \implies s_k = 16\left(\frac{1}{2}\right)^{k-1}.$$

Step 2 — Sum of all perimeters:

The perimeter of $T_1$ is $P_1 = 3 \times 16 = 48\text{ cm}$, and successive perimeters form a GP with common ratio $r_P = \dfrac{1}{2}$. Since $|r_P| = \dfrac{1}{2} \lt 1$, the infinite GP converges:

$$P_\infty = \frac{P_1}{1 - r_P} = \frac{48}{1 - \frac{1}{2}} = \frac{48}{\frac{1}{2}} = \mathbf{96\text{ cm}}.$$

Step 3 — Sum of all areas:

The area of $T_1$ is $A_1 = \dfrac{\sqrt{3}}{4}s_1^2 = \dfrac{\sqrt{3}}{4}(16)^2 = 64\sqrt{3}\text{ cm}^2$. Since similar triangles scale in area by the square of the linear scale factor, the areas form a GP with ratio $r_A = \left(\dfrac{1}{2}\right)^2 = \dfrac{1}{4}$. Since $|r_A| = \dfrac{1}{4} \lt 1$:

$$A_\infty = \frac{A_1}{1 - r_A} = \frac{64\sqrt{3}}{1 - \frac{1}{4}} = \frac{64\sqrt{3}}{\frac{3}{4}} = \mathbf{\frac{256\sqrt{3}}{3}\text{ cm}^2}.$$
Level 1 3-Variable Identities Worked Example 3: Zero-Arithmetic Evaluation of Large Cubes
Given $a = 2025$, $b = 2026$, and $c = 2028$, evaluate without direct squaring or cubing:

(b) $\dfrac{a^3 + b^3 + c^3 - 3abc}{a + b + c}$

Level 2 AP • Ratio Map & Means Worked Example 4: Ratio of AP Sums & Inserting $m$ Arithmetic Means
(a) The ratio of the sums of the first $n$ terms of two Arithmetic Progressions is $(7n + 1) : (4n + 27)$ for all positive integers $n$. Find the ratio of their $11^{\text{th}}$ terms.
(b) Between $5$ and $37$, $m$ arithmetic means are inserted such that the ratio of the $3^{\text{rd}}$ mean to the $(m - 1)^{\text{th}}$ mean is $1 : 3$. Find the value of $m$.

Part (a) — First-Principles Ratio Transformation:

Let the two APs be $(a_1, d_1)$ and $(a_2, d_2)$. For any positive integer $k$:

$$\frac{S_k}{S'_k} = \frac{\frac{k}{2}[2a_1 + (k - 1)d_1]}{\frac{k}{2}[2a_2 + (k - 1)d_2]} = \frac{a_1 + \left(\frac{k - 1}{2}\right)d_1}{a_2 + \left(\frac{k - 1}{2}\right)d_2} = \frac{7k + 1}{4k + 27}.$$

We need $\dfrac{T_{11}}{T'_{11}} = \dfrac{a_1 + 10d_1}{a_2 + 10d_2}$. Equate the coefficient of $d$:

$$\frac{k - 1}{2} = 10 \implies k = 2(11) - 1 = 21.$$

Substitute $k = 21$ into the given ratio:

$$\frac{T_{11}}{T'_{11}} = \frac{7(21) + 1}{4(21) + 27} = \frac{148}{111} = \frac{4 \times 37}{3 \times 37} = \mathbf{4 : 3}.$$

Part (b) — Inserting $m$ Arithmetic Means:

Inserting $m$ arithmetic means $A_1, A_2, \dots, A_m$ between $5$ and $37$ yields an AP of $(m + 2)$ terms with first term $a = 5$ and $(m + 2)^{\text{th}}$ term $b = 37$. Hence:

$$d = \frac{37 - 5}{m + 1} = \frac{32}{m + 1}.$$

Express the $3^{\text{rd}}$ mean $A_3$ and the $(m - 1)^{\text{th}}$ mean $A_{m-1}$ in terms of $d$ (note $A_k = a + kd$, and working backward from $b$, $A_{m-1} = b - 2d$):

$$A_3 = 5 + 3d, \qquad A_{m-1} = 37 - 2d.$$

Apply the given ratio $A_3 : A_{m-1} = 1 : 3$:

$$3(5 + 3d) = 37 - 2d \implies 15 + 9d = 37 - 2d \implies 11d = 22 \implies d = 2.$$

Now equate $d = \dfrac{32}{m + 1} = 2$:

$$m + 1 = 16 \implies \mathbf{m = 15}.$$

Verification: With $m = 15$ and $d = 2$, $A_3 = 5 + 6 = 11$ and $A_{14} = 5 + 28 = 33$, giving $11 : 33 = 1 : 3$.

Level 2 Olympiad Bridge • Infinite AGP Worked Example 5: Exact Evaluation of an Infinite AGP
Evaluate the exact sum of the infinite series: $$S = 1 + \frac{4}{3} + \frac{7}{9} + \frac{10}{27} + \frac{13}{81} + \dots$$

Step 1 — Identify the AP and GP components and verify convergence:

  • Numerators $1, 4, 7, 10, 13, \dots$ form an AP with $a = 1$, $d = 3$.
  • Denominators $1, 3, 3^2, 3^3, 3^4, \dots$ correspond to a GP with common ratio $r = \dfrac{1}{3}$.
  • Since $|r| = \dfrac{1}{3} \lt 1$, the infinite AGP is strictly convergent.

Step 2 — Execute Shift-and-Subtract:

$$ \begin{aligned} S &= 1 + \frac{4}{3} + \frac{7}{3^2} + \frac{10}{3^3} + \frac{13}{3^4} + \dots \\ \frac{1}{3}S &= \phantom{1 +\;} \frac{1}{3} + \frac{4}{3^2} + \frac{7}{3^3} + \frac{10}{3^4} + \dots \\ \hline \left(1 - \frac{1}{3}\right)S &= 1 + \frac{3}{3} + \frac{3}{3^2} + \frac{3}{3^3} + \frac{3}{3^4} + \dots \end{aligned} $$

Step 3 — Collapse the resulting pure infinite GP:

$$\frac{2}{3}S = 1 + 3\left(\frac{1}{3} + \frac{1}{3^2} + \frac{1}{3^3} + \dots\right) = 1 + 3\left(\frac{\frac{1}{3}}{1 - \frac{1}{3}}\right) = 1 + 3\left(\frac{1}{2}\right) = \frac{5}{2}.$$

Solve for $S$:

$$S = \frac{3}{2} \times \frac{5}{2} = \mathbf{\frac{15}{4}}.$$

Formula Cross-Check: $S_\infty = \dfrac{a}{1-r} + \dfrac{dr}{(1-r)^2} = \dfrac{1}{2/3} + \dfrac{3(1/3)}{(2/3)^2} = \dfrac{3}{2} + \dfrac{9}{4} = \dfrac{15}{4}$.

Level 2 Telescopic Series • Partial Fractions & Radicals Worked Example 6: Twin Telescoping — Triple Denominators & Odd Radicals
Compute the exact values of:
(a) $\displaystyle A = \frac{1}{1 \cdot 2 \cdot 3} + \frac{1}{2 \cdot 3 \cdot 4} + \frac{1}{3 \cdot 4 \cdot 5} + \dots + \frac{1}{18 \cdot 19 \cdot 20}$
(b) $\displaystyle B = \frac{1}{\sqrt{1} + \sqrt{3}} + \frac{1}{\sqrt{3} + \sqrt{5}} + \frac{1}{\sqrt{5} + \sqrt{7}} + \dots + \frac{1}{\sqrt{79} + \sqrt{81}}$

Write the $k$-th term $T_k = \dfrac{1}{k(k + 1)(k + 2)}$ for $k = 1, 2, \dots, 18$. Since $(k + 2) - k = 2$, rewrite the numerator $1$ as $\dfrac{1}{2}[(k + 2) - k]$:

$$T_k = \frac{1}{2}\cdot\frac{(k + 2) - k}{k(k + 1)(k + 2)} = \frac{1}{2}\left[\frac{1}{k(k + 1)} - \frac{1}{(k + 1)(k + 2)}\right].$$

Set $U_k = \dfrac{1}{k(k + 1)}$; then $T_k = \dfrac{1}{2}(U_k - U_{k+1})$. Summing from $k = 1$ to $18$ cancels all interior terms:

$$A = \frac{1}{2}\bigl(U_1 - U_{19}\bigr) = \frac{1}{2}\left(\frac{1}{1 \cdot 2} - \frac{1}{19 \cdot 20}\right) = \frac{1}{2}\left(\frac{1}{2} - \frac{1}{380}\right) = \frac{1}{2}\left(\frac{189}{380}\right) = \mathbf{\frac{189}{760}}.$$

Part (b) — Conjugate Radical Telescoping:

For each $k \in \{1, 2, \dots, 40\}$, rationalize the denominator of the $k$-th term:

$$\frac{1}{\sqrt{2k - 1} + \sqrt{2k + 1}} = \frac{\sqrt{2k + 1} - \sqrt{2k - 1}}{(2k + 1) - (2k - 1)} = \frac{1}{2}\bigl(\sqrt{2k + 1} - \sqrt{2k - 1}\bigr).$$

Sum from $k = 1$ to $40$:

$$B = \frac{1}{2}\Bigl[(\sqrt{3} - \sqrt{1}) + (\sqrt{5} - \sqrt{3}) + \dots + (\sqrt{81} - \sqrt{79})\Bigr] = \frac{\sqrt{81} - \sqrt{1}}{2} = \frac{9 - 1}{2} = \mathbf{4}.$$

Level 3 AM–GM • Weighted Splitting & Equality Trap Worked Example 7: Term-Splitting Optimization & Breaking the Unattainable Equality Trap
(a) Find the exact minimum value of $f(x) = 2x^3 + \dfrac{96}{x^2}$ for $x \gt 0$, and the value of $x$ at which it occurs.
(b) Find the exact minimum value of $g(x) = \dfrac{x^2 + 13}{\sqrt{x^2 + 9}}$ for all $x \in \mathbb{R}$.

Part (a) — Full Derivation via Weighted AM–GM Splitting:

Applying 2-term AM–GM directly to $2x^3$ and $\dfrac{96}{x^2}$ gives $2\sqrt{192x}$, which still depends on $x$ and fails to produce a constant bound. To eliminate $x$ completely in the product, the exponents $+3$ and $-2$ must balance to $0$. Since $\text{lcm}(3, 2) = 6$, we split $2x^3$ into $2$ equal parts and $\dfrac{96}{x^2}$ into $3$ equal parts:

$$f(x) = \underbrace{x^3 + x^3}_{2\text{ terms}} + \underbrace{\frac{32}{x^2} + \frac{32}{x^2} + \frac{32}{x^2}}_{3\text{ terms}}.$$

Since $x \gt 0$, all $5$ terms are strictly positive. Apply the 5-term AM–GM inequality:

$$\frac{x^3 + x^3 + \frac{32}{x^2} + \frac{32}{x^2} + \frac{32}{x^2}}{5} \ge \left(x^3 \cdot x^3 \cdot \frac{32}{x^2} \cdot \frac{32}{x^2} \cdot \frac{32}{x^2}\right)^{1/5} = \bigl(32^3\bigr)^{1/5} = \bigl((2^5)^3\bigr)^{1/5} = 2^3 = 8.$$

Multiply by $5$: $f(x) \ge 40$. Now verify attainability of equality (all $5$ split terms equal):

$$x^3 = \frac{32}{x^2} \implies x^5 = 32 \implies x = 2 \gt 0.$$

Since $x = 2$ lies inside $x \gt 0$, equality is achieved! Thus the exact minimum is $\mathbf{40}$ at $\mathbf{x = 2}$.

Part (b) — Resolving the Unattainable Equality Trap:

Rewrite $g(x)$ by splitting the numerator around $(x^2 + 9)$:

$$g(x) = \frac{(x^2 + 9) + 4}{\sqrt{x^2 + 9}} = \sqrt{x^2 + 9} + \frac{4}{\sqrt{x^2 + 9}}.$$

Let $t = \sqrt{x^2 + 9}$. Because $x^2 \ge 0$ for all $x \in \mathbb{R}$, the exact domain of $t$ is $t \ge 3$.

Why Naive AM–GM Fails: Applying AM–GM to $t + \dfrac{4}{t}$ yields $t + \dfrac{4}{t} \ge 2\sqrt{4} = 4$, with equality at $t = \dfrac{4}{t} \implies t = 2$. Because $t \ge 3$, $t = 2$ is unreachable, so $4$ is NOT the minimum!

Algebraic Monotonicity Proof (No Calculus Needed): Compare $h(t) = t + \dfrac{4}{t}$ against its boundary value $h(3) = 3 + \dfrac{4}{3} = \dfrac{13}{3}$ for any $t \ge 3$:

$$h(t) - h(3) = (t - 3) + \left(\frac{4}{t} - \frac{4}{3}\right) = (t - 3) - \frac{4(t - 3)}{3t} = (t - 3)\left(\frac{3t - 4}{3t}\right).$$

For every $t \ge 3$, we have $(t - 3) \ge 0$, $(3t - 4) \ge 5 \gt 0$, and $3t \gt 0$. Hence $h(t) \ge h(3) = \dfrac{13}{3}$ for all $t \ge 3$, with equality if and only if $t = 3 \iff x = 0$.

Therefore, the exact minimum value of $g(x)$ is $\mathbf{\dfrac{13}{3}}$ (attained at $x = 0$).

Level 3 3-Variable Identities • Two-Branch Logic Worked Example 8: Mastering Both Branches of $a^3 + b^3 + c^3 = 3abc$
(a) Real numbers $a, b, c$ satisfy $a + b + c = 12$ and $a^3 + b^3 + c^3 = 3abc$. Prove that $a = b = c$ and find the value of $a^2 + b^2 + c^2 + ab + bc + ca$.
(b) Three distinct non-zero real numbers $x, y, z$ satisfy $\dfrac{x^2}{yz} + \dfrac{y^2}{zx} + \dfrac{z^2}{xy} = 3$. Find the exact value of: $$E = \frac{(x - y)^3 + (y - z)^3 + (z - x)^3}{(x - y)(y - z)(z - x)} - \frac{x^3 + y^3 + z^3}{(x + y)(y + z)(z + x)}.$$

Part (a) — Triggering Branch 2 ($a = b = c$):

$$\frac{1}{2}(a + b + c)\Bigl[(a - b)^2 + (b - c)^2 + (c - a)^2\Bigr] = 0.$$

Substitute $a + b + c = 12 \neq 0$ and divide both sides by $6$:

$$(a - b)^2 + (b - c)^2 + (c - a)^2 = 0.$$

Since $a, b, c \in \mathbb{R}$, each square is non-negative, so all three must vanish simultaneously: $a - b = b - c = c - a = 0 \implies a = b = c$. Combined with $a + b + c = 12$, we get $a = b = c = 4$. Therefore:

$$a^2 + b^2 + c^2 + ab + bc + ca = 3(4^2) + 3(4^2) = 48 + 48 = \mathbf{96}.$$

Part (b) — Triggering Branch 1 ($x + y + z = 0$):

Clear denominators in the given equation by multiplying through by $xyz \neq 0$:

$$x^3 + y^3 + z^3 = 3xyz \implies \frac{1}{2}(x + y + z)\Bigl[(x - y)^2 + (y - z)^2 + (z - x)^2\Bigr] = 0.$$

Because $x, y, z$ are distinct, $(x - y)^2 + (y - z)^2 + (z - x)^2 \gt 0$. Dividing by this strictly positive bracket forces:

$$x + y + z = 0.$$

Now evaluate each fraction in $E$ separately:

  • First fraction: Let $u = x - y$, $v = y - z$, $w = z - x$. Notice $u + v + w = 0$ identically, and $uvw \neq 0$ (since $x, y, z$ are distinct). By Branch 1, $u^3 + v^3 + w^3 = 3uvw$, so: $$\frac{(x - y)^3 + (y - z)^3 + (z - x)^3}{(x - y)(y - z)(z - x)} = \frac{3uvw}{uvw} = 3.$$

Subtract the two values:

$$E = 3 - (-3) = \mathbf{6}.$$

Level 3 Olympiad Telescoping • Hidden Quartic Factor Worked Example 9: The Classic Quartic Telescopic Series $\sum \dfrac{k}{k^4 + k^2 + 1}$
Find the exact value of the sum: $$S = \sum_{k=1}^{20} \frac{k}{k^4 + k^2 + 1} = \frac{1}{3} + \frac{2}{21} + \frac{3}{91} + \dots + \frac{20}{160401}.$$

$$k^4 + k^2 + 1 = (k^4 + 2k^2 + 1) - k^2 = (k^2 + 1)^2 - k^2 = (k^2 - k + 1)(k^2 + k + 1).$$

30-Second Exam Trick

Lock two Olympiad signatures into permanent memory:
1. Factor trigger: $k^4 + k^2 + 1 = (k^2 - k + 1)(k^2 + k + 1)$ (also works for $4k^4 + 1 = (2k^2 - 2k + 1)(2k^2 + 2k + 1)$ via Sophie Germain!).
2. Closed sum: $\displaystyle \sum_{k=1}^{n} \frac{k}{k^4 + k^2 + 1} = \frac{n(n + 1)}{2(n^2 + n + 1)}$, and as $n \to \infty$, $S_\infty = \dfrac{1}{2}$. For $n = 20$: $\dfrac{20 \times 21}{2 \times 421} = \dfrac{210}{421}$ in 5 seconds flat.
