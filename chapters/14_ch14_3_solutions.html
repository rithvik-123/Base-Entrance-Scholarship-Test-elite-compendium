Q4 Level 1 Answer: (A)

Step 1 — Determine the Base via Pythagoras: Given $\sin\theta = \dfrac{m^2 - n^2}{m^2 + n^2}$ with $m \gt n \gt 0$, take perpendicular $p = (m^2 - n^2)k$ and hypotenuse $h = (m^2 + n^2)k$ ($k \gt 0$). Then:

$$ b = \sqrt{h^2 - p^2} = k\sqrt{(m^2 + n^2)^2 - (m^2 - n^2)^2} = k\sqrt{4m^2n^2} = 2mnk \qquad (\text{since } m, n \gt 0) $$

Q9 Level 2 Answer: (C)

Step 1 — Apply the Conjugate Pair Identity: Since $\sec\theta + \tan\theta = p$, its reciprocal conjugate is $\sec\theta - \tan\theta = \dfrac{1}{p}$. Adding and subtracting gives:

$$ \sec\theta = \frac{p + \frac{1}{p}}{2} = \frac{p^2 + 1}{2p}, \qquad \tan\theta = \frac{p - \frac{1}{p}}{2} = \frac{p^2 - 1}{2p} $$

Step 2 — Compute $\csc\theta$:

$$ \sin\theta = \frac{\tan\theta}{\sec\theta} = \frac{p^2 - 1}{p^2 + 1} \implies \csc\theta = \frac{1}{\sin\theta} = \frac{p^2 + 1}{p^2 - 1} $$

Step 3 — Apply Componendo and Dividendo:

$$ \frac{\csc\theta + 1}{\csc\theta - 1} = \frac{\frac{p^2 + 1}{p^2 - 1} + 1}{\frac{p^2 + 1}{p^2 - 1} - 1} = \frac{(p^2 + 1) + (p^2 - 1)}{(p^2 + 1) - (p^2 - 1)} = \frac{2p^2}{2} = \mathbf{p^2} $$

Alternative 10-Second Route: $\dfrac{\csc\theta + 1}{\csc\theta - 1} = \dfrac{1 + \sin\theta}{1 - \sin\theta} = \dfrac{(1 + \sin\theta)^2}{\cos^2\theta} = (\sec\theta + \tan\theta)^2 = p^2$. Therefore, the correct option is (C).

Chapter 14 Trap & Error Forensics

Trap Forensics #1 • The "Independent Max" Fallacy: $\max(a\sin\theta + b\cos\theta) \neq |a| + |b|$

The Fatal Error: Seeing $3\sin\theta + 4\cos\theta$, students substitute $\sin\theta = 1$ and $\cos\theta = 1$ simultaneously and write $\max = 3(1) + 4(1) = 7$ (or in Q17, $7(1) - 24(-1) + 30 = 61$).

Why It Fails: $\sin\theta$ and $\cos\theta$ are locked together by $\sin^2\theta + \cos^2\theta = 1$. Whenever $\sin\theta = 1$, $\cos\theta$ is forced to be $0$, never $1$ or $-1$.

The Antidote: Always collapse same-angle linear combinations into a single wave using the auxiliary-angle amplitude $R = \sqrt{a^2 + b^2}$. For $3\sin\theta + 4\cos\theta$, the true maximum is $\sqrt{3^2 + 4^2} = \mathbf{5}$ (attained at $\sin\theta = \frac{3}{5}, \cos\theta = \frac{4}{5}$), and in Q17, $R = \sqrt{7^2 + (-24)^2} = \mathbf{25}$, giving $[5, 55]$.

Trap Forensics #2 • Illegal Value Substitution at Boundary Singularities ($\theta = 0^\circ, 45^\circ, 90^\circ$)

The Fatal Error: To shortcut an MCQ identity containing $\tan\theta, \cot\theta, \sec\theta,$ or $\csc\theta$ (such as Q6: $\dfrac{\tan\theta}{1-\cot\theta} + \dfrac{\cot\theta}{1-\tan\theta}$), students reflexively plug in $\theta = 0^\circ$, $\theta = 90^\circ$, or $\theta = 45^\circ$, producing $\frac{0}{0}$ or $\infty - \infty$ and mis-evaluating the expression.

Why It Fails: $\tan 90^\circ$ and $\sec 90^\circ$ divide by $\cos 90^\circ = 0$; $\cot 0^\circ$ and $\csc 0^\circ$ divide by $\sin 0^\circ = 0$; and in Q6, $\theta = 45^\circ$ makes $1 - \tan 45^\circ = 0$ in the denominator.

The Antidote: Run a 2-second Denominator Audit before substituting any test angle. Never plug $\theta = 0^\circ$ or $90^\circ$ when any of $\{\tan, \cot, \sec, \csc\}$ appears. Default to $\theta = 45^\circ$ only when neither $(1 - \tan\theta)$ nor $(\sin\theta - \cos\theta)$ sits in a denominator; otherwise immediately use $\theta = 30^\circ$.

Trap Forensics #3 • The Cosine Compound-Angle Sign Inversion Error

The Fatal Error: Writing $\cos(A + B) = \cos A\cos B + \sin A\sin B$ or $\cos(A - B) = \cos A\cos B - \sin A\sin B$ by blindly copying the "same-sign" pattern of $\sin(A \pm B)$ (a classic killer in Q18, Q19, and Q27).

Why It Fails: In Q27, expanding $\cos(\theta - \frac{\pi}{6})$ with a minus sign turns $11\sin\theta + 4\sqrt{3}\cos\theta$ into $3\sin\theta + 4\sqrt{3}\cos\theta$, wrecking the amplitude from $13$ to $\sqrt{57}$. Similarly, in $\cos(45^\circ + 45^\circ) = \cos 90^\circ = 0$, the wrong sign gives $\frac{1}{2} + \frac{1}{2} = 1 \neq 0$.

The Antidote: Lock in the mnemonic: "Sine Keeps, Cosine Flips" — $\sin(A \pm B)$ keeps the $\pm$ sign, while $\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$ flips it. Under exam pressure, sanity-check with $A = B = 45^\circ$: $\cos(45^\circ + 45^\circ) = 0$ forces the minus sign.

Trap Forensics #4 • Dropping Absolute Value Bars on $\sqrt{\sin^2\theta} = |\sin\theta|$ Outside Quadrant I

The Fatal Error: Simplifying $\sqrt{1 - \cos^2\theta} = \sin\theta$ or $\sqrt{1 - \sin^2\theta} = \cos\theta$ blindly across all quadrants, or claiming $\sqrt{\frac{1+\sin\theta}{1-\sin\theta}} = \sec\theta + \tan\theta$ when $\theta \in (90^\circ, 270^\circ)$.

Why It Fails: The principal square root $\sqrt{x^2}$ is always non-negative, so $\sqrt{\sin^2\theta} = |\sin\theta|$ and $\sqrt{\cos^2\theta} = |\cos\theta|$. In Quadrant II (like Q14), $\cos\theta \lt 0$, so $\sqrt{\cos^2\theta} = -\cos\theta$, NOT $+\cos\theta$! In Q14, ignoring the Quadrant-II sign of $\cos\theta$ flips the answer from $-\frac{20}{39}$ to $+\frac{20}{39}$ (distractor A).

The Antidote: Write explicit absolute value bars $\sqrt{\cos^2\theta} = |\cos\theta|$ first, then consult the ASTC Chart for the exact quadrant of $\theta$ before removing the bars.

Trap Forensics #5 • Blind AM-GM Without Checking Domain Attainability (The Q24 & Q23 Killers)

The Fatal Error: Writing $\min(4\sin^2\theta + 9\csc^2\theta) = 2\sqrt{36} = 12$ (Q24 distractor A), or applying AM-GM separately to two coupled expressions in Q23 ($49 + 24 = 73$ instead of $75$).

Why It Fails: An AM-GM lower bound $x + y \ge 2\sqrt{xy}$ is the true minimum only if there exists a real angle $\theta$ where $x = y$ holds simultaneously across every term. For $4\sin^2\theta + 9\csc^2\theta$, equality demands $\sin^2\theta = \frac{3}{2} \gt 1$, which is impossible.

The Antidote: Every AM-GM calculation has a mandatory 2-step checklist: (1) combine all like trigonometric terms into a single expression first, and (2) solve the equality equation $x = y$ to confirm $\sin^2\theta, \cos^2\theta \in (0, 1]$ (or $\tan^2\theta \gt 0$). Whenever equality lies outside $(0, 1]$, the true minimum shifts to the boundary $\sin^2\theta = 1$ (giving $a + b$).
