1. Cartesian Plane, Distance Formula, Classification & Collinearity

First-Principles Foundation

In the rectangular Cartesian plane, every point $P(x, y)$ is located uniquely by its signed perpendicular distance $x$ (abscissa) from the $y$-axis and signed perpendicular distance $y$ (ordinate) from the $x$-axis.

Distance Formula (Pythagorean Derivation): Given $A(x_1, y_1)$ and $B(x_2, y_2)$, dropping perpendiculars to the axes forms a right triangle with horizontal leg $|x_2 - x_1|$ and vertical leg $|y_2 - y_1|$:

$$AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}, \qquad \text{Distance from Origin } O(0, 0): OP = \sqrt{x^2 + y^2}.$$

Triangle Classification via Squared Side Lengths: Let the three squared side lengths be $a^2 \le b^2 \le c^2$ (always compare squares to avoid radical arithmetic):

  • Right-angled: $a^2 + b^2 = c^2$ (right angle is strictly opposite the longest side $c$).
  • Acute-angled: $a^2 + b^2 \gt c^2$.   Obtuse-angled: $a^2 + b^2 \lt c^2$.
  • Equilateral / Isosceles: $a^2 = b^2 = c^2$ / any two equal. (Note: an equilateral triangle can never have all three vertices at integer lattice points in $\mathbb{R}^2$, because its area $\frac{\sqrt{3}}{4}a^2$ is irrational while the Shoelace formula gives a rational half-integer!)
Quadrilateral Classification Matrix (Cyclic Vertices $A, B, C, D$)

Always verify vertex order around the perimeter before classifying $ABCD$. Compute the four sides ($AB, BC, CD, DA$) and the two diagonals ($AC, BD$):

Quadrilateral Side Condition Diagonal Condition Critical Exam Trap
Parallelogram $AB = CD$ and $BC = DA$ Diagonals bisect each other: $\dfrac{A + C}{2} = \dfrac{B + D}{2}$ Fastest 4th vertex formula: $D = A + C - B$
Rectangle $AB = CD$ and $BC = DA$ Diagonals bisect each other AND $AC = BD$ Opposite sides equal is NOT enough; must check $AC = BD$

Three Independent Collinearity Tests for $A(x_1, y_1)$, $B(x_2, y_2)$, $C(x_3, y_3)$
  1. Distance Test: Sum of the two shorter distances equals the longest distance (e.g., $AB + BC = AC$). Slowest when radicals appear.
  2. Slope Test (Fastest for Concrete Numbers): $m_{AB} = m_{BC} \iff \dfrac{y_2 - y_1}{x_2 - x_1} = \dfrac{y_3 - y_2}{x_3 - x_2}$. Watch for the vertical-line case $x_1 = x_2 = x_3$ where slopes are undefined yet points are collinear!
  3. Zero-Area Determinant Test (Safest for Algebraic Parameters): $$x_1(y_2 - y_3) + x_2(y_3 - y_1) + x_3(y_1 - y_2) = 0.$$ Works unconditionally—even for vertical lines—without dividing by zero.

2. Section Formula: Internal, External & Arbitrary-Line Division

First-Principles Derivation (Internal & External Division)

1. Internal Division ($m : n$): Let $P(x, y)$ lie strictly between $A(x_1, y_1)$ and $B(x_2, y_2)$ such that $\dfrac{AP}{PB} = \dfrac{m}{n}$ ($m, n \gt 0$). Drawing horizontal and vertical legs yields two similar right triangles with side ratio $m : n$:

$$\frac{x - x_1}{x_2 - x} = \frac{m}{n} \implies n(x - x_1) = m(x_2 - x) \implies x = \frac{mx_2 + nx_1}{m + n}.$$

Applying the identical argument to $y$-coordinates gives:

$$P_{\text{int}} = \left(\frac{mx_2 + nx_1}{m + n},\; \frac{my_2 + ny_1}{m + n}\right), \qquad \text{Midpoint } (m = n = 1): M = \left(\frac{x_1 + x_2}{2},\; \frac{y_1 + y_2}{2}\right).$$
Resonance / Olympiad Bridge: External Division & Arbitrary Line Ratio Formula

2. External Division ($m : n$, $m \neq n$): Let $Q(x, y)$ lie on the line $AB$ outside segment $AB$ such that $\dfrac{QA}{QB} = \dfrac{m}{n}$. If $m \gt n$, $Q$ lies beyond $B$, so $B$ divides $AQ$ internally in the ratio $(m - n) : n$. Applying the internal formula to $B$:

$$x_2 = \frac{(m - n)x + n x_1}{m} \implies (m - n)x = mx_2 - nx_1 \implies x = \frac{mx_2 - nx_1}{m - n}.$$

The identical result holds when $m \lt n$ ($Q$ lies beyond $A$). Thus for any $m \neq n$:

$$Q_{\text{ext}} = \left(\frac{mx_2 - nx_1}{m - n},\; \frac{my_2 - ny_1}{m - n}\right).$$

Memory Lock: External division is literally internal division with $n$ replaced by $-n$!

3. Ratio $k : 1$ in Which an Arbitrary Line $L: ax + by + c = 0$ Divides Segment $AB$: Assume $L$ intersects the line $AB$ at $P = \left(\dfrac{kx_2 + x_1}{k + 1},\; \dfrac{ky_2 + y_1}{k + 1}\right)$. Since $P$ lies on $L$, substitute its coordinates into $ax + by + c = 0$ and multiply through by $(k + 1)$:

$$a(kx_2 + x_1) + b(ky_2 + y_1) + c(k + 1) = 0 \implies k(ax_2 + by_2 + c) + (ax_1 + by_1 + c) = 0.$$

Solving for $k$ yields the Master Line-Division Formula:

$$\text{Ratio } (k : 1) = -\frac{ax_1 + by_1 + c}{ax_2 + by_2 + c} = -\frac{L(A)}{L(B)}.$$
  • Sign Rule (Half-Plane Test): If $k \gt 0$ ($L(A)$ and $L(B)$ have opposite signs), $A$ and $B$ lie on opposite sides of $L \implies$ Internal Division. If $k \lt 0$ ($L(A)$ and $L(B)$ have the same sign), $A$ and $B$ lie on the same side of $L \implies$ External Division in ratio $|k| : 1$.
  • Instant Axis Corollaries: $x$-axis ($y = 0$) divides $AB$ in ratio $-\dfrac{y_1}{y_2}$; $\;y$-axis ($x = 0$) divides $AB$ in ratio $-\dfrac{x_1}{x_2}$.

Figure 11.1: Internal point $P$ lies between $A$ and $B$ ($L(A)$ and $L(B)$ carry opposite signs, giving $k \gt 0$); external point $Q$ lies outside segment $AB$ beyond $B$ when $m \gt n$.

3. Area of Triangles & Arbitrary Polygons: The Shoelace Engine

Triangle Area & Origin-Shift Speedup

For $\triangle ABC$ with vertices $A(x_1, y_1)$, $B(x_2, y_2)$, $C(x_3, y_3)$, dropping perpendiculars to the $x$-axis decomposes the triangle into three trapezoids, yielding:

$$\Delta = \frac{1}{2}\Bigl|x_1(y_2 - y_3) + x_2(y_3 - y_1) + x_3(y_1 - y_2)\Bigr|.$$

Origin-Shift Shortcut (Zero-Error Exam Trick): Translation preserves area! Subtract one vertex (say $A$) from all three vertices so $A$ moves to $(0, 0)$, $B \to (X_1, Y_1) = (x_2 - x_1, y_2 - y_1)$, and $C \to (X_2, Y_2) = (x_3 - x_1, y_3 - y_1)$. Then the formula collapses to a single $2 \times 2$ cross-product:

$$\Delta = \frac{1}{2}\bigl|X_1 Y_2 - X_2 Y_1\bigr|.$$
Resonance / Olympiad Bridge: The Shoelace (Staircase) Formula for $n$-Gons

For any non-self-intersecting $n$-sided polygon with vertices $(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)$ listed strictly in cyclic order (all clockwise or all counter-clockwise), list the vertices vertically and repeat the first vertex at the bottom:

$$\text{Area} = \frac{1}{2}\left|\sum_{i=1}^{n} (x_i y_{i+1} - y_i x_{i+1})\right|, \qquad \text{where } (x_{n+1}, y_{n+1}) = (x_1, y_1).$$

Why It Works (Signed Triangle Fan Proof): Every pair $(x_i, y_i) \to (x_{i+1}, y_{i+1})$ contributes $\frac{1}{2}(x_i y_{i+1} - y_i x_{i+1})$, the signed area of $\triangle O P_i P_{i+1}$ from the origin $O(0, 0)$. Summing around the closed boundary cancels all exterior overlap regions, leaving $+(\text{Area})$ for counter-clockwise order and $-(\text{Area})$ for clockwise order.

Critical Exam Trap: Cyclic Vertex Order in Polygons ($n \ge 4$)

For a triangle ($n = 3$), any permutation of vertices is automatically cyclic (clockwise or counter-clockwise). For a quadrilateral or higher polygon ($n \ge 4$), putting vertices out of cyclic order traces a self-intersecting "bow-tie" where opposite lobes have opposite signed areas and partially cancel out—giving a completely wrong answer! Always sketch a rough 2-second quadrant plot before running Shoelace on $n \ge 4$ points.

4. Straight Lines (Out-of-Portion Bridge): Slopes, Angles, Distance & Reflection

Resonance / Olympiad Bridge: Slopes, Standard Forms & Angle Between Lines

1. Inclination & Slope: If a line makes an angle $\theta \in [0^\circ, 180^\circ)$ counter-clockwise with the positive $x$-axis, its slope (gradient) is:

$$m = \tan\theta = \frac{y_2 - y_1}{x_2 - x_1} \qquad (x_1 \neq x_2).$$
  • Horizontal line ($\theta = 0^\circ$): $m = 0$ ($y = k$).   Vertical line ($\theta = 90^\circ$): $m$ is undefined ($x = k$).
  • Parallel lines: $m_1 = m_2$ (or both vertical).   Perpendicular lines: $m_1 m_2 = -1$ (or one horizontal, one vertical).

2. Five Essential Forms of a Straight Line:

  • Slope-Intercept Form: $y = mx + c$ (slope $m$, $y$-intercept $c$).
  • Point-Slope Form: $y - y_1 = m(x - x_1)$.
  • Two-Point Form: $y - y_1 = \dfrac{y_2 - y_1}{x_2 - x_1}(x - x_1)$.
  • Intercept Form: $\dfrac{x}{a} + \dfrac{y}{b} = 1$ ($x$-intercept $a \neq 0$, $y$-intercept $b \neq 0$; area with axes $= \dfrac{1}{2}|ab|$).
  • General Form: $ax + by + c = 0 \implies \text{slope } m = -\dfrac{a}{b}$.
    Instant Family Rules: Any line parallel to $ax + by + c = 0$ is $ax + by + \lambda = 0$; any line perpendicular to it is $bx - ay + \mu = 0$ (swap coefficients and flip one sign!).

3. Acute Angle $\theta$ Between Two Non-Vertical Lines ($m_1, m_2$): If $\theta_1, \theta_2$ are their inclinations, then $\theta = |\theta_1 - \theta_2|$ (or its supplement), and $\tan(\theta_1 - \theta_2) = \dfrac{\tan\theta_1 - \tan\theta_2}{1 + \tan\theta_1 \tan\theta_2}$ gives:

$$\tan\theta = \left|\frac{m_1 - m_2}{1 + m_1 m_2}\right| \qquad (m_1 m_2 \neq -1).$$

If $1 + m_1 m_2 = 0$, the lines are perpendicular ($\theta = 90^\circ$). If one line is vertical ($x = k$) and the other has slope $m$, the acute angle satisfies $\tan\theta = \dfrac{1}{|m|}$.

Resonance / Olympiad Bridge: Perpendicular Distance, Foot & Mirror Image

Let $P(x_1, y_1)$ be a point and $L: ax + by + c = 0$ ($a^2 + b^2 \gt 0$) be a straight line. Let $M(h, k)$ be the foot of the perpendicular from $P$ to $L$, and $P'(\alpha, \beta)$ be the mirror image (reflection) of $P$ across $L$.

First-Principles Derivation: The line $L$ has direction vector $(-b, a)$, so the perpendicular segment $PM$ is parallel to the normal vector $(a, b)$. Therefore, for some scalar $t \in \mathbb{R}$:

$$h - x_1 = at, \qquad k - y_1 = bt \quad \implies \quad h = x_1 + at,\quad k = y_1 + bt.$$

Because $M(h, k)$ lies on $L$, substitute into $ah + bk + c = 0$:

$$a(x_1 + at) + b(y_1 + bt) + c = 0 \implies (a^2 + b^2)t = -(ax_1 + by_1 + c) \implies t = -\frac{ax_1 + by_1 + c}{a^2 + b^2}.$$

This single scalar $t$ immediately unlocks all three master formulas:

  1. Foot of Perpendicular $M(h, k)$: $$\frac{h - x_1}{a} = \frac{k - y_1}{b} = -\frac{ax_1 + by_1 + c}{a^2 + b^2}.$$
  2. Mirror Image $P'(\alpha, \beta)$: Since $M$ is the midpoint of $PP'$, $\vec{PP'} = 2\vec{PM}$, so we simply double $t$: $$\frac{\alpha - x_1}{a} = \frac{\beta - y_1}{b} = -\frac{2(ax_1 + by_1 + c)}{a^2 + b^2}.$$
  3. Perpendicular Distance $d = PM$: $$d = \sqrt{(h - x_1)^2 + (k - y_1)^2} = \sqrt{(at)^2 + (bt)^2} = |t|\sqrt{a^2 + b^2} = \frac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}.$$
  4. Distance Between Two Parallel Lines $ax + by + c_1 = 0$ and $ax + by + c_2 = 0$: Pick any point $(x_1, y_1)$ on the first line (so $ax_1 + by_1 = -c_1$) and plug into the distance formula for the second line: $$d_{\parallel} = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}} \qquad \textbf{(MATCH } a, b \textbf{ COEFFICIENTS FIRST!)}$$

Figure 11.2: Geometry of orthogonal projection and reflection. Moving along normal $(a, b)$ by factor $t = -L(P)/(a^2 + b^2)$ lands at foot $M$; moving by $2t$ lands at exact mirror image $P'$.

5. Triangle Centers in Coordinates & The Euler Line Theorem

Resonance / Olympiad Bridge: Exact Coordinate Formulas for $G, I, O, H$

Consider $\triangle ABC$ with vertices $A(x_1, y_1)$, $B(x_2, y_2)$, $C(x_3, y_3)$ and opposite side lengths $a = BC$, $b = CA$, $c = AB$:

1. Centroid $G$ (Intersection of Medians):

The midpoint of $BC$ is $D\left(\frac{x_2+x_3}{2}, \frac{y_2+y_3}{2}\right)$. Since $G$ divides median $AD$ internally in the ratio $2 : 1$:

$$G = \left(\frac{2\left(\frac{x_2 + x_3}{2}\right) + 1 \cdot x_1}{2 + 1},\; \frac{2\left(\frac{y_2 + y_3}{2}\right) + 1 \cdot y_1}{2 + 1}\right) = \left(\frac{x_1 + x_2 + x_3}{3},\; \frac{y_1 + y_2 + y_3}{3}\right).$$

2. Incenter $I$ (Intersection of Internal Angle Bisectors):

Let the angle bisector of $\angle A$ meet $BC$ at $E$. By the Angle Bisector Theorem, $\dfrac{BE}{EC} = \dfrac{AB}{AC} = \dfrac{c}{b}$, so $E = \left(\dfrac{cx_3 + bx_2}{b + c},\; \dfrac{cy_3 + by_2}{b + c}\right)$ and $BE = \dfrac{ac}{b + c}$. Next, in $\triangle ABE$, the bisector $BI$ divides $AE$ in the ratio $\dfrac{AI}{IE} = \dfrac{AB}{BE} = \dfrac{c}{ac/(b+c)} = \dfrac{b + c}{a}$. Applying internal section division to $AE$ yields:

$$I = \left(\frac{ax_1 + bx_2 + cx_3}{a + b + c},\; \frac{ay_1 + by_2 + cy_3}{a + b + c}\right).$$

Warning: Each vertex $(x_1, y_1)$ is weighted by its OPPOSITE side length ($a = BC$), never an adjacent side!

3. Circumcenter $O$ (Intersection of Perpendicular Bisectors):

  • General method: Solve the two linear equations $OA^2 = OB^2$ and $OB^2 = OC^2$ (note that $x^2 + y^2$ cancels out identically!).
  • Right-Triangle Shortcut: If $\triangle ABC$ is right-angled at $A$, then $O$ is simply the midpoint of the hypotenuse $BC$: $O = \left(\dfrac{x_2 + x_3}{2}, \dfrac{y_2 + y_3}{2}\right)$, and circumradius $R = \dfrac{BC}{2}$.

4. Orthocenter $H$ (Intersection of Altitudes):

  • General method: Intersect any two altitudes (line through $A$ with slope $-1/m_{BC}$ and line through $B$ with slope $-1/m_{CA}$).
  • Right-Triangle Shortcut: If $\triangle ABC$ is right-angled at $A$, the two legs $AB$ and $AC$ are the altitudes, so $H = A$ (the right-angled vertex itself!).

5. The Euler Line Theorem (The Ultimate Coordinate Shortcut):

In every non-equilateral triangle, the Circumcenter $O$, Centroid $G$, and Orthocenter $H$ are strictly collinear (lying on the Euler Line), and $G$ divides segment $OH$ internally in the exact ratio $1 : 2$ ($OG : GH = 1 : 2$). By the section formula:

$$G = \frac{2O + 1 \cdot H}{3} \quad \iff \quad \mathbf{H = 3G - 2O}, \qquad O = \frac{3G - H}{2}.$$

Special Case: In an equilateral triangle, all four centers collapse to one point ($O = G = H = I$). Note that the Incenter $I$ does not lie on the Euler Line unless the triangle is isosceles!

Level 1: Warmup & Structural Calibration (Worked Examples 1–3)
Level 1 Distance • Quadrilateral Classification Worked Example 1: Rhombus vs. Square Trap & Parallelogram 4th Vertex
(a) Four points $A(1, 2)$, $B(4, 6)$, $C(9, 6)$, and $D(6, 2)$ are given in cyclic order. Determine the exact type of quadrilateral $ABCD$ (parallelogram, rectangle, rhombus, or square).
(b) Three vertices of a parallelogram $PQRS$ taken in order are $P(2, -1)$, $Q(5, 3)$, and $R(1, 6)$. Find the coordinates of the fourth vertex $S$.

Part (a) — Compute all four squared side lengths first:

$$ \begin{aligned} AB^2 &= (4 - 1)^2 + (6 - 2)^2 = 3^2 + 4^2 = 25 \implies AB = 5, \\ BC^2 &= (9 - 4)^2 + (6 - 6)^2 = 5^2 + 0^2 = 25 \implies BC = 5, \\ CD^2 &= (6 - 9)^2 + (2 - 6)^2 = (-3)^2 + (-4)^2 = 25 \implies CD = 5, \\ DA^2 &= (1 - 6)^2 + (2 - 2)^2 = (-5)^2 + 0^2 = 25 \implies DA = 5. \end{aligned} $$

Since all four sides are equal ($5$ units), $ABCD$ is either a rhombus or a square. Never stop here—test the diagonals!

$$AC^2 = (9 - 1)^2 + (6 - 2)^2 = 64 + 16 = 80 \implies AC = 4\sqrt{5},$$ $$BD^2 = (6 - 4)^2 + (2 - 6)^2 = 4 + 16 = 20 \implies BD = 2\sqrt{5}.$$

Because $AB = BC = CD = DA$ while $AC \neq BD$, quadrilateral $ABCD$ is strictly a rhombus (and NOT a square).

Part (b) — Use the Diagonal Midpoint Property:

In parallelogram $PQRS$, diagonals $PR$ and $QS$ share the exact same midpoint:

$$\left(\frac{x_P + x_R}{2},\; \frac{y_P + y_R}{2}\right) = \left(\frac{x_Q + x_S}{2},\; \frac{y_Q + y_S}{2}\right) \implies S = P + R - Q.$$ $$x_S = 2 + 1 - 5 = -2, \qquad y_S = (-1) + 6 - 3 = 2 \implies \mathbf{S = (-2, 2)}.$$
Level 1 Section Formula • Internal & External Worked Example 2: Comparing Internal and External Division on the Same Segment
Given $A(-2, 5)$ and $B(4, -7)$, find the coordinates of:
(a) point $P$ that divides segment $AB$ internally in the ratio $2 : 1$;
(b) point $Q$ that divides segment $AB$ externally in the ratio $5 : 2$.

Part (a) — Internal Division ($m = 2,\; n = 1$):

$$x_P = \frac{2(4) + 1(-2)}{2 + 1} = \frac{8 - 2}{3} = 2, \qquad y_P = \frac{2(-7) + 1(5)}{2 + 1} = \frac{-14 + 5}{3} = -3.$$

Hence $\mathbf{P = (2, -3)}$.

Part (b) — External Division ($m = 5,\; n = 2$):

Apply $Q = \left(\dfrac{mx_2 - nx_1}{m - n},\; \dfrac{my_2 - ny_1}{m - n}\right)$ with $(x_1, y_1) = (-2, 5)$ and $(x_2, y_2) = (4, -7)$:

$$x_Q = \frac{5(4) - 2(-2)}{5 - 2} = \frac{20 + 4}{3} = 8, \qquad y_Q = \frac{5(-7) - 2(5)}{5 - 2} = \frac{-35 - 10}{3} = -15.$$

Hence $\mathbf{Q = (8, -15)}$.

Sanity Check: $QA = \sqrt{(8 - (-2))^2 + (-15 - 5)^2} = \sqrt{500} = 10\sqrt{5}$ and $QB = \sqrt{(8 - 4)^2 + (-15 - (-7))^2} = \sqrt{80} = 4\sqrt{5}$, confirming $QA : QB = 10\sqrt{5} : 4\sqrt{5} = 5 : 2$.

Level 1 Straight Lines • Forms & Perpendicularity Worked Example 3: Perpendicular Construction & Intercept-Form Lines
(a) Find the equation of the straight line passing through $(3, -4)$ and perpendicular to the line $2x - 5y + 7 = 0$.
(b) Find the equations of all straight lines passing through $(2, 2)$ whose $x$- and $y$-intercepts sum to $9$.

Part (a) — Perpendicular Line through $(3, -4)$:

Rewrite $2x - 5y + 7 = 0$ as $y = \dfrac{2}{5}x + \dfrac{7}{5}$, giving slope $m_1 = \dfrac{2}{5}$. For perpendicularity ($m_1 m_2 = -1$):

$$m_2 = -\frac{5}{2}.$$

Using Point-Slope Form through $(3, -4)$:

$$y - (-4) = -\frac{5}{2}(x - 3) \implies 2y + 8 = -5x + 15 \implies \mathbf{5x + 2y - 7 = 0}.$$

Family Check: Swap coefficients and flip one sign: $5x + 2y + \mu = 0$; substituting $(3, -4)$ gives $15 - 8 + \mu = 0 \implies \mu = -7$.

Part (b) — Intercept Form with $a + b = 9$:

Let the $x$-intercept be $a$ and $y$-intercept be $b = 9 - a$ ($a \neq 0, 9$). The line is $\dfrac{x}{a} + \dfrac{y}{9 - a} = 1$. Since it passes through $(2, 2)$:

$$\frac{2}{a} + \frac{2}{9 - a} = 1 \implies 2(9 - a) + 2a = a(9 - a) \implies 18 = 9a - a^2 \implies a^2 - 9a + 18 = 0.$$

Factor: $(a - 3)(a - 6) = 0 \implies a = 3$ or $a = 6$.

  • If $a = 3$, then $b = 6$: $\dfrac{x}{3} + \dfrac{y}{6} = 1 \implies \mathbf{2x + y - 6 = 0}$.
  • If $a = 6$, then $b = 3$: $\dfrac{x}{6} + \dfrac{y}{3} = 1 \implies \mathbf{x + 2y - 6 = 0}$.
Level 2: Exam-Real BEST / NTSE Stage 2 Standard (Worked Examples 4–6)
Level 2 Section Bridge • Line Division Ratio Worked Example 4: Ratio in Which an Arbitrary Line Cuts Segment $AB$
Find the ratio in which the line $3x + y - 9 = 0$ divides the line segment joining $A(1, 3)$ and $B(2, 7)$. State whether the division is internal or external, and find the exact coordinates of the point of intersection $P$.

Step 1 — First-Principles Derivation Using $k : 1$:

Let $P$ divide $AB$ in the ratio $k : 1$. By the section formula:

$$P = \left(\frac{2k + 1}{k + 1},\; \frac{7k + 3}{k + 1}\right).$$

Since $P$ lies on $3x + y - 9 = 0$, substitute $x$ and $y$ and multiply through by $(k + 1)$:

$$3(2k + 1) + (7k + 3) - 9(k + 1) = 0 \implies (6k + 7k - 9k) + (3 + 3 - 9) = 0 \implies 4k - 3 = 0 \implies k = \frac{3}{4}.$$

Step 2 — Cross-Check with the Instant Line-Ratio Formula:

Set $L(x, y) = 3x + y - 9$. Evaluate at $A(1, 3)$ and $B(2, 7)$:

$$L(A) = 3(1) + 3 - 9 = -3, \qquad L(B) = 3(2) + 7 - 9 = +4 \implies k = -\frac{L(A)}{L(B)} = -\frac{-3}{4} = \frac{3}{4}.$$

Since $k = \dfrac{3}{4} \gt 0$ (opposite signs at $A$ and $B$), the line divides $AB$ internally in the ratio $3 : 4$.

Step 3 — Find the Intersection Point $P$:

$$x_P = \frac{3(2) + 4(1)}{3 + 4} = \frac{10}{7}, \qquad y_P = \frac{3(7) + 4(3)}{3 + 4} = \frac{33}{7} \implies \mathbf{P = \left(\frac{10}{7},\; \frac{33}{7}\right)}.$$

Verification: $3\left(\frac{10}{7}\right) + \frac{33}{7} - 9 = \frac{63}{7} - 9 = 0$.

$A(-3, 2)$ lies in Q2, $B(5, 4)$ in Q1, $C(7, -6)$ in Q4, and $D(-5, -4)$ in Q3. Moving $A \to B \to C \to D$ traces a clean clockwise boundary with no self-intersections.

Level 2 Straight Lines • Angle & Parallel Distance Worked Example 6: Acute Angle Between Lines & Parallel-Line Normalization Trap
(a) Find the acute angle between the lines $y - \sqrt{3}x - 5 = 0$ and $\sqrt{3}y - x + 6 = 0$.
(b) Find the perpendicular distance between the parallel lines $3x - 4y + 9 = 0$ and $6x - 8y - 17 = 0$.

Part (a) — Angle Formula:

Extract both slopes cleanly:

$$L_1: y = \sqrt{3}x + 5 \implies m_1 = \sqrt{3}; \qquad L_2: y = \frac{1}{\sqrt{3}}x - 2\sqrt{3} \implies m_2 = \frac{1}{\sqrt{3}}.$$

Apply $\tan\theta = \left|\dfrac{m_1 - m_2}{1 + m_1 m_2}\right|$:

$$\tan\theta = \left|\frac{\sqrt{3} - \frac{1}{\sqrt{3}}}{1 + \sqrt{3} \cdot \frac{1}{\sqrt{3}}}\right| = \left|\frac{\frac{3 - 1}{\sqrt{3}}}{1 + 1}\right| = \frac{2/\sqrt{3}}{2} = \frac{1}{\sqrt{3}} \implies \mathbf{\theta = 30^\circ}.$$

Part (b) — Match Coefficients Before Applying $d_{\parallel} = \dfrac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$:

Notice that $3x - 4y + 9 = 0$ and $6x - 8y - 17 = 0$ do NOT yet have identical $(a, b)$ coefficients! Multiply the first equation by $2$ so both lines share $(a, b) = (6, -8)$:

$$L_1: 6x - 8y + 18 = 0 \quad (c_1 = 18), \qquad L_2: 6x - 8y - 17 = 0 \quad (c_2 = -17).$$

Now apply the parallel-line distance formula:

$$d_{\parallel} = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}} = \frac{|18 - (-17)|}{\sqrt{6^2 + (-8)^2}} = \frac{35}{\sqrt{36 + 64}} = \frac{35}{10} = \mathbf{\frac{7}{2}\text{ units}}.$$

Level 3 Straight Lines • Foot & Mirror Reflection Worked Example 7: Foot of Perpendicular, Mirror Image & Shortest Distance
For the point $P(3, 8)$ and the straight line $L: x + 3y - 7 = 0$, find:
(a) the shortest distance from $P$ to $L$;
(b) the foot of the perpendicular $M(h, k)$ dropped from $P$ onto $L$;
(c) the mirror image $P'(\alpha, \beta)$ of $P$ with respect to $L$.

Full First-Principles Derivation (Simultaneous Lines + Midpoint):

Step 1 — Shortest distance from $P(3, 8)$ to $L: 1\cdot x + 3\cdot y - 7 = 0$:

$$d = \frac{|1(3) + 3(8) - 7|}{\sqrt{1^2 + 3^2}} = \frac{|3 + 24 - 7|}{\sqrt{10}} = \frac{20}{\sqrt{10}} = \mathbf{2\sqrt{10}\text{ units}}.$$

Step 2 — Equation of the perpendicular line $PM$:

Slope of $L$ is $m_L = -\dfrac{1}{3}$, so slope of $PM$ is $m_{PM} = 3$. Passing through $P(3, 8)$:

$$y - 8 = 3(x - 3) \implies 3x - y - 1 = 0 \implies y = 3x - 1.$$

Step 3 — Solve $L$ and $PM$ simultaneously for $M(h, k)$:

$$x + 3(3x - 1) - 7 = 0 \implies 10x - 10 = 0 \implies x = 1, \quad y = 3(1) - 1 = 2.$$

Thus the foot of the perpendicular is $\mathbf{M = (1, 2)}$.

Step 4 — Use $M$ as the midpoint of $PP'$ to find mirror image $P'(\alpha, \beta)$:

$$\frac{3 + \alpha}{2} = 1 \implies \alpha = -1, \qquad \frac{8 + \beta}{2} = 2 \implies \beta = -4 \implies \mathbf{P' = (-1, -4)}.$$

• Image $P'$: $(x_1 + 2at,\; y_1 + 2bt) = (3 + 1(-4),\; 8 + 3(-4)) = \mathbf{(-1, -4)}$.

Level 3 Triangle Centers • Right-Triangle Mastery Worked Example 8: Computing All Four Centers ($G, I, O, H$) & Verifying Euler's Law
Find the Centroid $G$, Incenter $I$, Circumcenter $O$, and Orthocenter $H$ of $\triangle ABC$ with vertices $A(0, 0)$, $B(8, 0)$, and $C(0, 6)$, and verify that $H = 3G - 2O$.

Step 1 — Compute side lengths opposite $A, B, C$:

$$c = AB = 8, \qquad b = CA = 6, \qquad a = BC = \sqrt{(8 - 0)^2 + (0 - 6)^2} = \sqrt{64 + 36} = 10.$$

Notice $6^2 + 8^2 = 10^2 \implies \triangle ABC$ is right-angled at $A(0, 0)$.

Step 2 — Centroid $G$:

$$G = \left(\frac{0 + 8 + 0}{3},\; \frac{0 + 0 + 6}{3}\right) = \mathbf{\left(\frac{8}{3},\; 2\right)}.$$

Step 3 — Incenter $I$ (weighting each vertex by its opposite side):

$$x_I = \frac{a x_A + b x_B + c x_C}{a + b + c} = \frac{10(0) + 6(8) + 8(0)}{10 + 6 + 8} = \frac{48}{24} = 2,$$ $$y_I = \frac{a y_A + b y_B + c y_C}{a + b + c} = \frac{10(0) + 6(0) + 8(6)}{10 + 6 + 8} = \frac{48}{24} = 2 \implies \mathbf{I = (2, 2)}.$$

Step 4 — Circumcenter $O$ & Orthocenter $H$ from First Principles:

  • Circumcenter $O$: Perpendicular bisector of $AB$ is $x = 4$; perpendicular bisector of $AC$ is $y = 3$. They intersect at $\mathbf{O = (4, 3)}$.
  • Orthocenter $H$: Altitude from $B(8, 0)$ to $AC$ ($x = 0$) is $y = 0$; altitude from $C(0, 6)$ to $AB$ ($y = 0$) is $x = 0$. They intersect at $\mathbf{H = (0, 0)}$.

Step 5 — Verify Euler Line Formula $H = 3G - 2O$:

$$3G - 2O = 3\left(\frac{8}{3},\; 2\right) - 2(4, 3) = (8, 6) - (8, 6) = (0, 0) = H \quad \checkmark$$

Level 3 Olympiad Bridge • Euler Line Acceleration Worked Example 9: Circumcenter & Orthocenter of a General Triangle via $H = 3G - 2O$
Find the Circumcenter $O$, Centroid $G$, and Orthocenter $H$ of the triangle with vertices $A(-2, 3)$, $B(2, -1)$, and $C(4, 0)$.

Step 1 — Centroid $G$:

$$G = \left(\frac{-2 + 2 + 4}{3},\; \frac{3 + (-1) + 0}{3}\right) = \mathbf{\left(\frac{4}{3},\; \frac{2}{3}\right)}.$$

Step 2 — Circumcenter $O(x, y)$ from $OA^2 = OB^2 = OC^2$:

First equate $OA^2 = OB^2$:

$$(x + 2)^2 + (y - 3)^2 = (x - 2)^2 + (y + 1)^2 \implies 4x + 4 - 6y + 9 = -4x + 4 + 2y + 1 \implies 8x - 8y = -8 \implies y = x + 1.$$

Next equate $OB^2 = OC^2$:

$$(x - 2)^2 + (y + 1)^2 = (x - 4)^2 + y^2 \implies -4x + 4 + 2y + 1 = -8x + 16 \implies 4x + 2y = 11.$$

Substitute $y = x + 1$ into $4x + 2y = 11$:

$$4x + 2(x + 1) = 11 \implies 6x = 9 \implies x = \frac{3}{2}, \qquad y = \frac{3}{2} + 1 = \frac{5}{2} \implies \mathbf{O = \left(\frac{3}{2},\; \frac{5}{2}\right)}.$$

Step 3 — Orthocenter $H$ (Full Altitude Intersection Derivation):

  • Slope of $BC = \dfrac{0 - (-1)}{4 - 2} = \dfrac{1}{2} \implies$ altitude through $A(-2, 3)$ has slope $-2$: $$y - 3 = -2(x + 2) \implies 2x + y = -1.$$
  • Slope of $AC = \dfrac{0 - 3}{4 - (-2)} = -\dfrac{1}{2} \implies$ altitude through $B(2, -1)$ has slope $+2$: $$y - (-1) = 2(x - 2) \implies 2x - y = 5.$$

Add both altitude equations: $4x = 4 \implies x = 1$; then $y = -1 - 2(1) = -3$. Hence $\mathbf{H = (1, -3)}$.

Once you have $G = \left(\dfrac{4}{3}, \dfrac{2}{3}\right)$ and $O = \left(\dfrac{3}{2}, \dfrac{5}{2}\right)$, never touch altitude equations! Apply $H = 3G - 2O$ directly: $$H = 3\left(\frac{4}{3},\; \frac{2}{3}\right) - 2\left(\frac{3}{2},\; \frac{5}{2}\right) = (4, 2) - (3, 5) = \mathbf{(1, -3)}.$$ Conversely, if altitudes are simpler to solve than $OA^2 = OB^2 = OC^2$, find $H$ first and recover $O = \dfrac{3G - H}{2}$ in 5 seconds!
